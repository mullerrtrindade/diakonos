DIAK TECNOLOGIA — NOVA VERSÃO

COMO VISUALIZAR
Extraia todo o ZIP e abra index.html no navegador. Mantenha os arquivos e a pasta assets juntos.

COMO ATUALIZAR O SITE
Copie o conteúdo deste pacote para a pasta do seu site, substituindo os arquivos correspondentes. Envie a atualização pelo mesmo fluxo Git/Cloudflare que você já utiliza. A publicação no seu domínio não foi feita automaticamente por este pacote.

SEUS CONTATOS
WhatsApp, e-mail e Instagram continuam centralizados no config.js. Os valores do arquivo enviado foram preservados. O formulário apenas prepara a mensagem; o visitante confirma o envio no WhatsApp.

O QUE FOI ADICIONADO
Visual azul-marinho com luzes e interação por mouse/toque; portfólio do ConectaCell; apresentação de Müller e da história da DIAK; diagnóstico de quatro etapas; mensagem revisável e opção de copiar; menu móvel; controle para pausar animações.

CONECTACELL
A interface no portfólio é uma demonstração ilustrativa com dados fictícios. As abas, o filtro e a abertura dos detalhes funcionam apenas na prévia; não criam ordens de serviço reais. O programa desktop não foi alterado.

CONTEÚDO E IMAGENS
A foto está em assets/muller-trindade.jpeg. Os textos podem ser alterados no index.html. Não há vídeo nesta versão, conforme a última seleção de conteúdo.

COMPATIBILIDADE
HTML, CSS e JavaScript puros, sem etapa de build ou dependências de execução. O wrangler.jsonc e o config.js originais foram preservados. As fontes do Google são opcionais; se não carregarem, o site usa fontes do sistema. As respostas do diagnóstico não são armazenadas e não há novo serviço de analytics.

VERIFICAÇÃO
Navegação desktop e em larguras móveis, demonstração do ConectaCell, validação do diagnóstico, preservação das respostas, geração do link de WhatsApp, cópia e arquivos locais conferidos.
