SITE DA DIAK TECNOLOGIA — HTML para Cloudflare Pages
=====================================================

O que há no projeto
------------------
- index.html: textos e estrutura do site.
- styles.css: cores, espaçamentos e design responsivo.
- main.js: menu para celular, animações e formulário de contato.
- config.js: configurações de contato (EDITE ANTES DE PUBLICAR).
- assets/: logos em PNG com fundo transparente e favicon.

ETAPA 1: CONFIGURE O CONTATO (IMPORTANTE)
---------------------------------------
Abra config.js no Bloco de Notas ou VS Code. Preencha os campos:

window.DIAK_CONFIG = {
  whatsapp: "5511999999999",
  email: "seu-email@exemplo.com",
  instagram: "https://www.instagram.com/seuperfil/"
};

Esses valores são APENAS EXEMPLOS. Use seus dados reais.
Você pode deixar e-mail e Instagram vazios, mas recomenda-se adicionar ao menos
um WhatsApp real. Digite o WhatsApp somente com números, incluindo 55 e DDD.

Com WhatsApp configurado, o formulário abre uma conversa no WhatsApp do
visitante com a mensagem preparada; a pessoa ainda precisa confirmar o envio.
Com e-mail configurado, mas sem WhatsApp, ele abre o aplicativo de e-mail do
visitante. Se nenhum dos dois for preenchido, a pessoa poderá copiar a
mensagem, mas NÃO enviá-la diretamente à DIAK.

O site é estático e NÃO salva os dados preenchidos no formulário.
Não há backend, banco de dados ou cobrança mensal do código.

ETAPA 2: VERIFIQUE O SITE
------------------------
Abra o arquivo index.html no navegador. Os links de navegação são âncoras e
funcionam localmente. Verifique o menu no celular e o formulário.

ETAPA 3: PUBLIQUE NO CLOUDFLARE PAGES
-------------------------------------
1. Acesse https://dash.cloudflare.com/ e entre em Workers & Pages.
2. Escolha Create application > Get started > Drag and drop your files.
3. Defina o nome do projeto (ex.: diak-tecnologia, se disponível).
4. Envie o ZIP DIAK_SITE_PARA_CLOUDFLARE.zip OU a pasta com os arquivos.
5. Clique em Deploy site.
6. Acesse o endereço gerado, como nome-do-projeto.pages.dev.

IMPORTANTE: O ZIP foi montado com index.html NA RAIZ, conforme necessário.
Se for editar o site mais tarde, faça o deploy de um novo ZIP.
Para publicação por GitHub com deploys automáticos, crie outro projeto usando
integração Git: um projeto Direct Upload não pode ser convertido para Git
posteriormente.

AJUSTES RÁPIDOS
---------------
- Alterar cores: edite as variáveis no início do styles.css.
- Alterar textos: edite os conteúdos do index.html.
- Alterar logo: substitua os arquivos na pasta assets preservando os nomes.
- Alterar WhatsApp e Instagram: config.js.
- Este pacote não contém dados fictícios de clientes, resultados ou depoimentos.
- Após definir um domínio próprio, poderá configurar SEO mais avançado.

Documentação oficial:
https://developers.cloudflare.com/pages/get-started/direct-upload/
